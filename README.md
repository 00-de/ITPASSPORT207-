# ITパスポート合格ナビ2027 — Phase 1

React + TypeScript + Vite + Tailwind CSS v3 / PWA対応。
Phase 1 の時点では、学習データは端末のブラウザ（localStorage）に保存されます。Firebase 連携は Phase 2 で追加します。

## 収録内容

- 問題：28問（シラバス Ver.6.5 準拠。生成AI・RAG・ハルシネーション・AIガバナンス・中小受託取引適正化法を含む）
- 用語：70語（検索・お気に入り・暗記カード対応）

## 実装済みの機能

| 画面 | 内容 |
| --- | --- |
| ホーム | 受験日カウントダウン、今日の進捗、連続学習日数、正解率、レベル、学習メニュー、週間プラン |
| 一問一答 | 4択出題、正誤判定、解説表示、類似問題の追加出題、結果集計と誤答一覧 |
| 苦手問題 | 分野別正解率をもとに、弱い分野から優先出題 |
| 模擬試験 | 本番形式（最大100問／120分）、前後移動、時間切れ自動採点、分野別スコアと合否判定 |
| 用語辞典 | 用語・よみ・意味・分野の横断検索、お気に入り登録 |
| 暗記カード | 表（用語）／裏（意味）のめくり学習。お気に入りのみの出題も可能 |
| 学習記録 | 直近14日の学習量グラフ、分野別正解率、苦手ランキング、模試履歴、実績10種 |
| 設定 | ユーザー名、受験予定日、1日の目標問題数、データ消去 |

## 動かし方（GUI操作のみ）

### そのままVercelに公開する

1. このフォルダごと GitHub Desktop で新しいリポジトリに追加してコミット・公開する
2. Vercel で「Add New → Project」からそのリポジトリを選ぶ
3. Framework Preset は **Vite** を選択（Build Command `npm run build` / Output Directory `dist` が自動で入ります）
4. 「Deploy」を押すだけで公開されます

### 手元で確認する場合

`npm install` のあと `npm run dev`。ブラウザで表示されたURLを開きます。

# Phase 2：Firebase連携（ログイン＋クラウド同期）

## できること

- メールアドレス／Googleアカウントでのログイン・新規登録
- パスワードの再設定メール送信
- 学習記録（解答ログ・日別記録・模試履歴・実績・お気に入り・プロフィール）をFirestoreに保存
- 別の端末でログインすると記録を引き継ぎ、両方の記録を突き合わせて統合
- ログインせずに端末内だけで使うことも可能（あとから設定画面でログインすれば、その端末の記録が引き継がれます）

## 設定手順（GUI操作のみ）

### 1. Firebaseコンソール

1. Firebaseコンソールでプロジェクトを作成
2. 「Authentication」→「始める」→ Sign-in method で **メール/パスワード** と **Google** を有効にする
3. 「Firestore Database」→「データベースの作成」→ 本番環境モードで作成
4. 「ルール」タブを開き、このプロジェクトの `firestore.rules` の内容を貼り付けて公開
5. プロジェクトの設定 → マイアプリ → ウェブアプリを追加し、表示された設定値を控える

### 2. Vercel

1. Vercel のプロジェクト → Settings → Environment Variables を開く
2. `.env.example` にある6つの名前で、控えた設定値を登録する
3. Deployments からもう一度 Redeploy する（環境変数は再デプロイで反映されます）

### 3. 承認済みドメインの追加

Firebaseコンソール → Authentication → Settings → 承認済みドメイン に、Vercelで発行されたドメイン（`〇〇.vercel.app` と独自ドメイン）を追加します。これを忘れるとGoogleログインが失敗します。

## 動作のしかた

- 解答はまず端末内に保存され、約2.5秒後にまとめてクラウドへ書き込みます。通信が切れても学習は止まりません
- ログイン直後は「同期中…」、完了で「同期済み」がヘッダーに出ます
- 1ドキュメントの容量制限に配慮し、解答ログは新しいものから4,000件まで保持します

## セキュリティ

`firestore.rules` により、`users/{uid}` は本人だけが読み書きできます。それ以外のパスはすべて拒否です。`VITE_` から始まる環境変数はブラウザに公開されますが、Firebaseの設定値は公開前提の値であり、保護はAuthenticationとFirestoreルールで行います。

# Phase 3：AI先生（Groq／ChatGPT 自動切替）

## しくみ

APIキーはVercelのサーバ側だけに置き、`/api/ai` を経由して呼び出します。ブラウザにキーは渡りません。

1. 既定はGroq（応答が速く、無料枠が広い）
2. Groqが応答しない・上限に達した場合は、ChatGPTへ自動で切り替えて答える
3. 設定画面から「自動／Groq／ChatGPT」を手動で選べる
4. 片方のキーだけ登録した場合は、そちらだけを使う
5. どちらも未登録なら「まだ設定されていません」と表示され、他の機能は通常どおり使える

## できること

- **AI先生タブ**：日本語で自由に質問。苦手分野を添えて質問するので、答えが学習状況に沿う
- **もっと簡単に説明して**：問題の解説画面から、その問題をやさしく言い換えてもらう
- **苦手分野から1問つくってもらう**：一番弱い分野の問題をAIが新しく作り、その場で解ける

AIが作った問題は学習記録に加算しません（正誤の信頼性が公式問題とは異なるため）。

## 設定手順

### 1. APIキーを取る

- Groq：console.groq.com → API Keys → Create API Key
- OpenAI：platform.openai.com → API keys → Create new secret key（従量課金の登録が必要）

どちらか一方だけでも動きます。まずGroqだけで試すのがおすすめです。

### 2. Vercelに登録

Settings → Environment Variables で、次の名前で登録します。**`VITE_` は付けません。**

| Key | 値 |
| --- | --- |
| `GROQ_API_KEY` | Groqのキー |
| `OPENAI_API_KEY` | OpenAIのキー |
| `FIREBASE_API_KEY` | （任意）VITE_FIREBASE_API_KEY と同じ値 |

`FIREBASE_API_KEY` を入れると、ログイン済みの人だけがAI先生を使えるようになります。第三者にAPIを使われて費用が増えるのを防ぐため、公開サイトでは登録を推奨します。

登録後、Deployments から Redeploy してください。

### 3. 確認

AI先生タブで質問し、回答の下に「GROQ」または「CHATGPT」と表示されれば、どちらが答えたか分かります。

## 注意

- `npm run dev` のローカル開発では `/api/ai` が動きません（Vercel上でのみ動作します）。ローカルで試す場合は `vercel dev` を使います
- AIの回答は誤りを含むことがあります。最終確認は公式シラバスで行ってください
