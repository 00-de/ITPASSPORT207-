# ITパスポート合格ナビ2027 — Phase 1

React + TypeScript + Vite + Tailwind CSS v3 / PWA対応。
Phase 1 の時点では、学習データは端末のブラウザ（localStorage）に保存されます。Firebase 連携は Phase 2 で追加します。

## 収録内容

- 問題：28問（シラバス Ver.6.5 準拠。生成AI・RAG・ハルシネーション・AIガバナンス・中小受託取引適正化法を含む）
- 用語：70語（検索・お気に入り・暗記カード対応）

## 実装済みの機能

| 画面 | 内容 |
| --- | --- |
| ホーム | 受験日カウントダウン、今日の進捗、連続学習日数、正解率、レベル、学習メニュー、週間プラン |
| 一問一答 | 4択出題、正誤判定、解説表示、類似問題の追加出題、結果集計と誤答一覧 |
| 苦手問題 | 分野別正解率をもとに、弱い分野から優先出題 |
| 模擬試験 | 本番形式（最大100問／120分）、前後移動、時間切れ自動採点、分野別スコアと合否判定 |
| 用語辞典 | 用語・よみ・意味・分野の横断検索、お気に入り登録 |
| 暗記カード | 表（用語）／裏（意味）のめくり学習。お気に入りのみの出題も可能 |
| 学習記録 | 直近14日の学習量グラフ、分野別正解率、苦手ランキング、模試履歴、実績10種 |
| 設定 | ユーザー名、受験予定日、1日の目標問題数、データ消去 |

## 動かし方（GUI操作のみ）

### そのままVercelに公開する

1. このフォルダごと GitHub Desktop で新しいリポジトリに追加してコミット・公開する
2. Vercel で「Add New → Project」からそのリポジトリを選ぶ
3. Framework Preset は **Vite** を選択（Build Command `npm run build` / Output Directory `dist` が自動で入ります）
4. 「Deploy」を押すだけで公開されます

### 手元で確認する場合

`npm install` のあと `npm run dev`。ブラウザで表示されたURLを開きます。
